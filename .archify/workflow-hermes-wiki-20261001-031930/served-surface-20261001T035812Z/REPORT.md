# 최종 HTML 렌더링 재검증

## 판정: REVISE — 동작 확인과 화면 가독성은 별개

검증 대상은 최종 로컬 `index.html`과 다이어그램 8개다. 1440×900과 375×812, 총 18개 화면/크기 조합을 실제 브라우저에서 열었다. HTTP 서버를 띄우거나 배포 앱을 시험한 것은 아니다. 검사 중 HTML/JSON 명세는 수정하지 않았다.

## 관찰된 결과

| 항목 | 결과 |
|---|---|
| 페이지 전체 및 일반 본문 가로 넘침 | 18개 조합에서 관찰되지 않음 |
| 목차 | 양 크기에서 제목/본문/링크 잘림·겹침 미관찰. Tab 첫 포커스는 건너뛰기 링크. 주의문 펼치기·첫 다이어그램 클릭·뒤로 가기 확인 |
| 도식 조작 | 16개 조합에서 테마 전환·검색 결과 없음·Escape 닫기·검색 버튼 포커스 복귀 확인 |
| 모바일 검색 모달 | 8개 캡처에서 입력·결과 없음·닫기 버튼의 뚜렷한 잘림/겹침 없음. 작은 회색 안내는 덜 선명함 |
| 수집한 페이지 오류 | error 0, unhandled rejection 0, console.error 0. 초기 페이지 hook이 존재함을 함께 확인 |
| 외부 리소스 | 수집한 Resource Timing에 HTTP(S) 리소스 0. 네트워크/배포 통합 정상의 증거는 아님 |
| 캡처·실물 | 원 캡처 46개, surface/viewport 18개. 캡처 SHA-256 및 대상 HTML SHA-256 일치 |

## 수정이 필요한 관찰

1. **모바일 글자 크기:** workflow 전체를 좁은 캔버스에 축소해 설명·연결 라벨을 읽기 어렵다. 데스크톱 보조 글씨도 작고 옅다. DOM 크기 추정은 진단값이며 숫자 하나로 가독성 PASS를 판정하지 않았다.
2. **모바일 도식 일부 화면 밖:** 01·02·07의 기본 화면에서 노드·라벨이 오른쪽 밖에 있다. 내부 가로 탐색이 가능해도 첫 화면 가독성 통과는 아니다.
3. **확대 조작 발견성:** 하단 도구막대의 +가 초기에는 가려진다. 대표 01·04·07·08은 도구막대를 가로 스크롤한 뒤 실제 포인터 클릭 시 100%→125% 전환했다. 버튼 핸들러 자체가 고장 났다고 보고하지 않는다.
4. **한국어 UI:** 07·08의 경로/렌즈가 모바일에서 세로로 쪼개진다. 01–06 HTML 언어/UI는 영어이며, 한국어 본문과 일관되지 않는다.
5. **조밀한 경로:** 04·05·06 데스크톱 첫 화면에서 떠 있는 하단 조작부가 도식 영역 위에 놓인다. 전체 페이지 스크롤이 존재한다는 사실을 도식 읽기 품질의 보증으로 쓰지 않는다.

모바일 하단 설명 카드 표본은 정상 세로스크롤 안에서 표시됐고 뚜렷한 가로 잘림·겹침은 없었다. 일부 한글/영문 경로의 어절 중간 줄바꿈은 남는다.

## 근거와 한계

- `plan.json`: 검사 범위·금지 작업.
- `observations.jsonl`: 실제 DOM·동작·오류 hook·하단 상태 18개 기록.
- `capture-manifest.json`: 캡처별 원본 HTML·viewport·상태·SHA-256.
- `summary.json`: 수치 집계, 중복·누락 대조.
- `mobile-controls.json`: 초기 + 위치, 내부 가로스크롤, 실제 클릭 후 배율.
- `verdict.json`: 점수·REVISE 판정·근거별 최소 수정 제안.
- `*-desktop-mobile.png`, `finders-*.png`: 실제 캡처를 이어 붙인 검토용 이미지이며 합성 UI가 아니다.

화면 캡처는 기본 상태의 모든 대상, 모바일 검색 모달 전체, 일부 하단 카드/주의문을 이미지 도구로 검토했다. 모든 아래 카드·모든 테마·모든 viewer 모드·Export·전체 키보드 순서·스크린리더를 시각 전수 검토했다고 주장하지 않는다. 이번 요청은 검증/보고이므로 수정 작업이나 새 finalize는 실행하지 않았다.

브라우저 QA hook 해제 명령은 `Script not found`, QA target 닫기 명령은 `Specified target does not support closing`을 반환했다. 이는 위 페이지 오류 계수와 별도의 harness 관리 실패다. 마지막 새 목차 탭에서는 `qaHookPresent=false`를 실제 확인했으며 대상 HTML 파일은 변경되지 않았다.
