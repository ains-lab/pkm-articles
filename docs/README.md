# 논문 Wiki 사용 설명서

논문을 **모으는 일**과 **읽고 정리하는 일**은 서로 다릅니다. 이 폴더는 현재 자동화가 어디까지 하는지 쉽게 설명합니다.

## 먼저 읽을 문서

- [논문 수집 자동화 — 쉬운 안내](paper-collection.md)
  - 매일 무엇을 모으는지
  - 어떤 파일이 어디에 저장되는지
  - HTML이 없거나 같은 논문을 다시 만났을 때의 처리
  - 제거한 전처리와 별도로 요청하는 Wiki 정리
  - 현재 상태와 확인 방법
